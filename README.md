# Midterm Quotation App

This is a quotation app built with React, Vite, and MUI for the WAD Midterm Exam.

## Features
- Add, merge, and delete quotation items
- Input for quantity and discount
- Real-time calculation of total discount and amount
- JSON data loading for item options
- Responsive UI using Material-UI
